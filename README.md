# 🛒 Superstore Sales Analysis Dashboard – Power BI

## 📊 Project Overview
The **Superstore Analysis Dashboard** is a data visualization and business intelligence project developed using Microsoft Power BI. This dashboard helps analyze sales, profit, discount, quantity, and other business metrics to understand overall business performance.

The dashboard presents business data through interactive visualizations and KPI cards, making it easier to identify trends, compare categories, and gain meaningful insights from sales data.

## 🎯 Objectives
- Analyze overall sales and profit performance.
- Understand sales trends and patterns.
- Analyze quantity sold across different categories.
- Examine the impact of discounts on sales.
- Compare business performance across different regions.
- Present data in an interactive and easy-to-understand format.

## 🛠️ Tools & Technologies Used
- **Microsoft Power BI Desktop**
- **Data Visualization**
- **Data Analytics**
- **Superstore Dataset**

## 📈 Dashboard Features
- Sales KPI
- Profit KPI
- Discount KPI
- Sales and Discount Trend Analysis
- Profit Analysis by Order ID
- Quantity and Profit by Category
- Sales and Quantity Analysis
- Regional Performance Analysis
- Interactive charts and visualizations

## 📊 Key Metrics
- **Total Sales:** 2.30M
- **Total Discount:** 1.56K
- **Total Profit:** 286.40K

## 💡 Key Insights
- The dashboard provides an overview of total sales and profit.
- It helps identify profitable product categories.
- It allows analysis of quantity sold across different categories.
- It helps understand sales and discount trends.
- It supports better business decision-making through data visualization.
